# Benchmark Public-Data Qualification

NSE Indices exposes separate historical index-data and total-return-index report paths. Its methodology says a price index excludes ordinary dividend receipts while total return incorporates and reinvests them.

No PRI/TRI data object was downloaded in A.7. Date coverage, publication timing, revisions, retention, and permitted use remain `UNKNOWN`; this is source identification, not sample qualification.

Validation requires distinct stable identifiers such as `NIFTY50_PRI` and `NIFTY50_TRI` and explicit classifications. Equal identifiers, missing classifications, or PRI-for-TRI substitution fail. The system cannot claim total-return comparison from PRI evidence.
