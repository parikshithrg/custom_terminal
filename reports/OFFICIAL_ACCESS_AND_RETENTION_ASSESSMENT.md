# Official Access and Retention Assessment

This is an evidence classification, not legal advice.

| Question | Status | Evidence/limitation |
|---|---|---|
| Public accessibility | PASS | Official reports, archives, circulars and policies are reachable |
| Individual manual download | PASS / REQUIRES_REVIEW | Copyright policy describes personal, non-commercial or educational downloading; exact scope needs review |
| Systematic automated retrieval | FAIL | Current NSE Terms of Use prohibit systematic/automated collection |
| Reasonable automated rate | REQUIRES_REVIEW | Pacing does not override the prohibition |
| Local immutable retention | REQUIRES_REVIEW | Terms/copyright/data policy do not clearly authorize this archive workflow |
| Correction-version retention | UNKNOWN | No public correction-vintage commitment established |
| Derived personal research use | REQUIRES_REVIEW | Data policy contemplates researcher agreements/conditions |
| Redistribution | FAIL unless expressly permitted | Raw data is not committed |
| Display | REQUIRES_REVIEW | Display conditions may require underlying documentation |

Technical accessibility is not permission. Fifteen bounded objects were obtained before the current automated-collection restriction was identified; acquisition then stopped. No CAPTCHA, authentication, access control, or rate limit was bypassed.

Written clarification from NSE/NSE Data is required for manual download, immutable retention, and non-commercial derived research. If clarification requires paid subscription, this project remains blocked because paid providers are prohibited.
